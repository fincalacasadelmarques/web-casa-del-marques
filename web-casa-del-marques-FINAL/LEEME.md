# Web de la Casa del Marqués

Esta es la web completa (HTML, CSS y JavaScript). Cloudflare la publica automáticamente cada vez que se cambia algo aquí.

## Cambios rápidos (desde la web de GitHub)

- **Cambiar un texto**: abre la carpeta de la página (por ejemplo `casa-rural`), pulsa en `index.html`, luego en el lápiz ✏️, cambia el texto y pulsa **Commit changes**. En un minuto está en la web.
- **Cambiar una foto**: entra en `img` (o `img/galeria`), pulsa **Add file → Upload files** y sube una foto con el **mismo nombre** que la que quieres sustituir.
- **Añadir fotos a la galería**: súbelas a `img/galeria` y añade una línea en `js/galeria-fotos.js`.
- **Colores y letras**: al principio de `css/estilos.css`.

Si algo sale mal, en **Commits** se puede volver a cualquier versión anterior.
